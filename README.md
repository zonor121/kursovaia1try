# Graph Visualizer Pro

Современное интерактивное приложение для визуализации работы алгоритмов поиска кратчайшего пути на графах: **Дейкстры** и **Беллмана-Форда**.

## 📋 Описание

Это курсовой проект, реализующий пошаговую визуализацию алгоритмов кратчайшего пути. Приложение позволяет:

- Загружать пользовательские графы из текстовых файлов
- Генерировать случайные графы
- Визуализировать процессы алгоритмов в реальном времени
- Использовать интуитивный интерфейс с горячими клавишами
- Работает с ориентированными и неориентированными графами
- Поддерживает отрицательные веса рёбер (Беллман-Форд)

## 🎯 Функционал

### Основные возможности
- **Визуализация графов**: Автоматическое позиционирование узлов с возможностью масштабирования и панорамирования
- **Пошаговое выполнение**: Шаги алгоритма с подробными описаниями изменений
- **История выполнения**: Перемотка вперёд-назад по шагам
- **Интерактивное управление**: Горячие клавиши для быстрого управления
- **Результаты**: Таблица расстояний и путей с подсветкой

### Поддерживаемые алгоритмы
1. **Алгоритм Дейкстры** - поиск кратчайшего пути, не работает с отрицательными весами
2. **Алгоритм Беллмана-Форда** - работает с отрицательными весами, обнаруживает циклы отрицательной веса

## 📖 Использование

### Формат файла графа
Создайте текстовый файл с рёбрами графа:

```
A B 4
B C 3
C D 5
START A
END D
```

- Каждая строка: `узел1 узел2 вес`
- Необязательные команды: `START узел`, `END узел`, `DIRECTED`, `UNDIRECTED`

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Пробел` | Старт/Пауза анимации |
| `Стрелка →` | Следующий шаг |
| `Стрелка ←` | Предыдущий шаг |
| `R` | Перезапуск алгоритма |
| `F` | Полноэкранный режим |
| `+` / `-` | Изменить скорость |
| `I` | Сброс просмотра |
| `G` | Генерировать случайный граф |
| `L` | Загрузить граф |
| `1` / `2` | Переключить алгоритм (Дейкстра/Беллман-Фронд) |
| `H` | Показать справку |
| `Esc` | Выйти из полноэкранного режима |

### Интерфейс
- **Графическое полотно**: Средняя область с визуализацией
- **Панель управления**: Верхняя - алгоритмы, управление; Правая - настройки, результаты
- **Колесико мыши**: Масштабирование графа
- **Средняя кнопка мыши**: Панорамирование
